# Hermes 笔记助手

让 Hermes 融入思源，把文档、对话和任务串成一个工作空间。

## 核心功能

- 💬 **边写笔记，边与 Hermes 协作**——围绕当前文档提问、讨论，梳理思路。
- 🔎 **查找与引用笔记**——搜索笔记中的资料，把相关内容带入对话。
- 📝 **把回答留下来**——将有用的回答保存为笔记，或整理成任务草稿。
- 🔗 **关联任务**——连接任务插件中的待办，与相关文档和对话一起查看、跟进。
- 🗂️ **集中到工作空间**——围绕一项工作归集文档、资料、对话和任务，方便随时继续。

> 使用前需先安装 Hermes；任务关联功能需配合任务插件使用。
